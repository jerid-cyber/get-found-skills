# Get-Found Skills Library (Version 3)

The Top 100 Claude Skills for helping businesses get found and grow, built on the 4-Phase System (Discovery & Assessment, Architecture & Design, Implementation & Deployment, Optimization & Governance). **40 of the 100 are organic search skills (SEO, GEO and AEO).** Skills are ranked by how many businesses each one helps.

## How to use

Each folder in `skills/` is a standalone Claude Skill with a `SKILL.md`. Upload a skill folder (zipped) in Claude under Settings > Capabilities > Skills, or package groups of them into a plugin.

Every skill follows the same engine: no baseline, no build; exposure ends at a revenue signal; and in a zero-click world, brand mentions and AI citations are measured alongside traffic. See [METHODOLOGY.md](METHODOLOGY.md).
